# SE Color Picker

A modern Chrome extension for picking, managing, and exporting colors with a beautiful Apple-inspired Material 3 interface.

## Features

- 🎨 Pick colors from any webpage
- 🌈 Create and manage color palettes
- 📋 Copy colors in HEX, RGB, HSL, and CSS formats
- 💾 Save favorite colors locally
- ⚡ Fast, lightweight, and privacy-friendly
- 🧊 Modern glassmorphism UI inspired by Apple + Material 3
